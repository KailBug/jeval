# Synthetic Codex rollout fixture

`classic.jsonl` is entirely synthetic. It contains no user session data and makes no claim about a specific Codex release. `synthetic-classic-fixture` is a fixture label, not a CLI version.

The classic fixture covers session/fork metadata, a mirrored user message, canonical text messages, a function call and failed output, a turn completion marker, an unknown record, and a malformed line. The HTML-like output must render as plain text. Source order and physical line numbers are intentionally stable for evidence assertions.

`paginated.jsonl` is also entirely synthetic, constructed after inspecting the structure of a user-authorized Codex 0.160.0 file. It contains no copied private messages or identifiers. It covers parent-thread metadata, canonical/projected message deduplication in both physical orders, identical text in different turns, projected-only messages with `Text` content, tool relationships, and known non-display metadata. Expected output is 9 events with no warnings; the real source file is never committed.

See the [adapter mapping and limitations](../../../docs/adapters/codex.md). Boundary inputs such as oversized text, incomplete final lines, and malformed metadata are generated by tests rather than checked in as large files.

The separate [public CodexBar corpus](public/codexbar/README.md) is derived from real upstream fork metadata under MIT, with documented redactions and unknown original CLI version. It is not one of the synthetic fixtures above and does not contain private local trajectories. The [source matrix](../../../docs/adapters/codex-source-matrix.md) distinguishes public derivatives, authorized local evidence and synthetic regressions.
