# Synthetic Codex rollout fixture

`classic.jsonl` is entirely synthetic. It contains no user session data and makes no claim about a specific Codex release. `synthetic-classic-fixture` is a fixture label, not a CLI version.

The fixture covers session/fork metadata, a mirrored user message, canonical text messages, a function call and failed output, a turn completion marker, an unknown record, and a malformed line. The HTML-like output must render as plain text. Source order and physical line numbers are intentionally stable for evidence assertions.

See the [adapter mapping and limitations](../../../docs/adapters/codex.md). Boundary inputs such as oversized text, incomplete final lines, and malformed metadata are generated by tests rather than checked in as large files.
