## D01 已交付任务卡

- 目标：用户更新一个已登记 Codex 来源时可利用持久化检查点，重启后可继续，归一化结果与完整重读一致。
- 范围：Go 更新/存储、必要的版本化契约与迁移、现有桌面更新入口的进度/失败反馈、跨进程与打包 E2E、M2 进度及相关文档。进入 M2 时建立进度文档并更新索引。
- 排除：新文件自动导入、文件监听、配额扩容、全文存储、轨迹视觉重做、其他来源和 Jev。
- 语义：优先正确性；不能安全续读时回退完整重读并记录原因。检查点与快照事务一致；只读交换来源不可更新。
- 用例：重复更新、追加完整行、半行补全、截断/轮转/替换、投影先到 canonical 后到、取消、进程中断与恢复、源文件离线。逐项比较事件/父关系/未知值/快照证据与完整重读基线，保留旧快照及源摘要。
- 端到端：导入 → 追加 → 点击更新 → 检查新内容和证据 → 重启 → 再更新；失败或取消后原记录可浏览，新文件仍须候选确认。使用独立资料库和合成样本，真实兼容矩阵由 A01 补齐。
- 检查：`npm run check`、开发 E2E、`npm run pack`、随包存储检查和打包 E2E；具体环境变量见运行指南。格式、链接及最新 PR CI 一并验收。
- 状态：已合并至 main `84fc7f2` 并同步；最终 push/PR CI 均通过，本地检查和限制见 M2 进度。本轮另获“继续”进入 A01。
