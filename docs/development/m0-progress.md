## Paginated 导入修复与窗口历史导航

2026-10-04，PR #2 合并后，用户提供了一份不能导入的真实记录。只读检查发现来源为 Codex 0.160.0、history_mode=paginated；上一版的 classic 白名单提前拒绝了该文件。

- 支持 paginated，并处理 `item_completed` 的 UserMessage/AgentMessage 投影；优先 canonical 消息，按 ID 或同回合角色/文本去重，跨回合相同提示保留，只有投影时仍可显示。识别 Text 文本块，已知环境、设置和内部推理行不产生重复的未知类型提示。
- 导入信息展示记录模式与父线程，父线程与 fork 来源分别保留。导入错误移除 Electron IPC 包装文字，直接展示原因。
- 窗口顶部重复品牌替换为左右箭头，保留原生窗口按钮和拖动区域。历史可在记录和来源之间前进/后退，恢复筛选、处理失效记录，最多 100 项；不新增任意导航/文件操作权限。
- 重新构造 paginated fixture，覆盖双重表示、乱序投影、跨回合同文、投影回退与工具关联；没有提交真实会话内容、路径、标识或截图。

验证：`npm run check`、未打包的 2 项 E2E、`npm run pack`、最终目录包的 2 项 E2E 均通过。新增桌面断言覆盖箭头禁用、记录/来源前后导航、分支清除及拖动/no-drag 样式；截图在 1440/1000 宽度检查。用户指定的真实文件在开发构建和最终目录包中导入通过，解析出 107 个事件、55 条消息，3 页读取，全部证据行号有效，源文件校验不变；12 项提示全部是长正文预览截断。窗口原生覆盖层报告可见。

范围：这只是一个真实消息/回合样本的验证，不能宣称所有 0.160.0 工具投影均兼容。自动化通过替换文件选择器返回值触发真实 IPC/Go 读取；系统对话框人工操作、窗口按钮实际点击、多平台、完整安装与持久化仍未验收。

## Codex 单文件导入切片（此前记录）

2026-10-04，PR #1 合并后，在同一功能分支快进到 main，开始首个来源的受控导入。

- 新增经典 Codex rollout JSONL 只读解析器：消息、工具调用/结果、回合状态、错误、会话与分支来源、实际物理行号和原始字节摘要。
- 使用原生文件选择器导入单文件；渲染层不能提交任意文件路径。支持演示/Codex 来源切换、空结果、取消、独立错误提示、解析提示与来源证据。
- 同一路径重复导入替换旧快照，致命解析失败保留旧记录；文件、行数、事件、文本预览和内存记录数量均有明确上限。
- 回合结束不当作整个会话成功；未知指标仍为 null。未知类型、坏行、半行、内容截断均给出提示。增加按编码字节预算的事件分页，避免长工具输出撑破协议帧。
- 更新双语 README、协议、记录草案、适配器、架构、运行与界面说明。合成样本来源说明随 fixture 保存，无私人日志进入仓库。

本轮本机验证：`npm run check` 通过（类型、Go 单元测试、4 项跨进程测试、生产构建）；未打包 Electron 的 2 项 E2E 通过；`npm run pack` 成功更新目录包，并用最终包通过 2 项 E2E。桌面覆盖取消、缺失文件、导入、重复导入、提示、普通文本展示、来源切换和重启后清空；文件选择器返回值由测试替换，实际读取使用打包 Go 引擎。截图检查覆盖 1440 与 1000 宽度，窄窗口无页面横向溢出。

交付前核对 15 份 Markdown 的 84 个本地链接，目标均存在；`git diff --check` 通过。本轮远程 CI 状态以 PR checks 为准。

验证边界：仅有人工构造的 classic 格式样本，不等于真实 Codex 发布版本验收；尚未人工验收系统文件选择器、NSIS 安装或干净环境。本轮未实现自动发现、持久化、增量同步、导出或 Jev。导入随引擎退出清空，源文件更新需再次导入，刷新只查询内存快照。映射与限制见 [适配器](../adapters/codex.md)，截图见 [界面说明](../design/m0-ui.md)。

## 首次桌面与引擎实现范围

依据已有开发规划，从空目录骨架开始搭建第一个可运行的桌面与引擎切片。首发验证平台暂定 Windows；首个本地来源为用户已确认的 Codex。

已实现：

- npm workspace；Electron、React、TypeScript、electron-vite；纯 Go 标准库引擎。
- 主进程启动独立引擎、版本握手、请求匹配、超时、失败反馈、显式重连与退出清理。
- 搜索、状态筛选、按页查询；完成、失败、未知三类合成样例。
- 任务列表、执行时间线、可展开工具输出、来源与父事件引用、未知指标显示。
- TypeScript/Go 协议与最小记录草案；Go 单元测试、真实子进程集成测试和 Electron 流程测试。
- 引擎嵌入演示数据；桌面目录包/Windows NSIS 配置通过 extraResources 携带引擎。

构建选择为 electron-vite 5 + Vite 7（按 peer dependency 兼容范围选择）。当前不引入 SQLite 驱动，避免在尚无真实记录和持久化需求验证前锁定存储方案。
