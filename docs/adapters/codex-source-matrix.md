## 来源与可公开范围

本地样本只从 Codex sessions 的历史日期目录与 archived_sessions 中选择候选。执行日期为 2026-10-07；按三个日历月限定，全部顶层事件时间和 session_meta 时间必须早于 `2026-07-07T00:00:00+08:00`。8 份候选中 7 份符合条件；L06 虽在较早日期目录中，最后事件时间晚于截止，未送入引擎或桌面验收。没有读取近期轨迹正文进行测试。

私人原件只读；验证在忽略目录中的字节相同副本和独立 SQLite 库上进行。公开材料只含样本代号、摘要、版本、数量、时间范围和验证结论，不含路径、会话标识、消息、工具参数、截图或 trace。本地路径清单不纳入 Git；要复验这些私人样本，需样本所有者在本地提供与摘要一致的获准文件，CI 无法复验私人内容。

P01/P02 来自 MIT 授权的 CodexBar 固定提交 `eda352c17d41d8bbb55b6b4b1c5cf2a5588bc536`；上游说明它们从真实分支脱敏衍生，仅保留元数据与用量。原字节、许可证、下载路径及摘要见 [公开样本说明](../../fixtures/adapters/codex/public/codexbar/README.md)。其 2030 时间、会话别名为脱敏值，不能作为真实执行日期；没有 cli_version/history_mode，不能补造版本。它们不是完整对话。

## 可复核方式

[来源审计工具](../../scripts/validation/codex-source-audit.ts) 只接受显式清单，不自动扫描、不联网、不运行来源内容。按摘要和时间资格检查后，在独立临时库核对 canonical 覆盖、来源正文预览、时间/行号/父关系、未知值、分页、重启、更新和离线交换。结果为允许公开的统计；失败不打印断言的实际/预期正文。桌面工具使用相同资格检查，再通过真实 Electron IPC 和按钮逐页核对序号；文件选择器返回值由测试提供，不是原生选择器人工验收。

公开样本可直接复验：

```powershell
npm run build
node --import tsx scripts/validation/run-codex-audit.ts source fixtures/adapters/codex/public/manifest.json .local/public-source-report.json
node --import tsx scripts/validation/run-codex-audit.ts desktop fixtures/adapters/codex/public/manifest.json .local/public-desktop-report.json
```

私人清单在本地创建，样本字段参考 [公开清单](../../fixtures/adapters/codex/public/manifest.json)，provenance 改为 local-historical，提供 notAfter、确切路径、sha256 和复核后的预期数量。必须先确认用户授权及三个日历月截止，不能把私有样本改标为 public-sanitized 来跳过时间门槛。工具只验证明确截止日，不自行推断使用授权。原始 bytes 的完整 SHA-256 保存在统计报告，private path 不进入报告。

最终目录包使用 `JEVAL_AUDIT_EXECUTABLE=release/win-unpacked/resources/engine/jeval-engine.exe`，桌面另设 `JEVAL_PACKAGED_EXECUTABLE=release/win-unpacked/jeval.exe` 后运行同一命令。运行记录及最终 CI 见 [M0 进度](../development/m0-progress.md)。CI 仅使用已提交的公开样本与合成拒绝用例，不能据其绿灯新增私人来源兼容声明。
